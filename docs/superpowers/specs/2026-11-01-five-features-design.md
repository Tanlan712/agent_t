# 五項功能：商店歷史、重置倒數、今日小結、本機備份、主題排程（2026-11-01）

使用者在功能清單中選了 1–5 全做。全部只用已同步／已讀到的資料，不新增 Riot 端點或請求（AGENTS.md 第 3 節「使用者決定 2026-11-01」）。

## 1. 商店歷史

- `RiotProvider.sync` 成功後呼叫 `onShopSynced(puuid, shop)`，`ShopHistoryProvider` 記下每日商店（4 款與價格）與夜市。
- 以到期時間辨識同一輪（差距 2 小時內視為同一輪，因為到期時間由剩餘秒數推算）；各帳號分開存在 `shop_history_v1_<puuid>`，
  每日最多 1000 輪、夜市最多 100 期。登出不刪除（不含機密）。
- `/shop-history` 頁：KPI（記錄天數、出現過的造型、夜市期數）、搜尋造型（上次出現日期、每日商店次數、夜市次數、最後價格）、
  「每天的商店」與「出現次數」兩種檢視。入口在首頁的重置倒數卡。

## 2. 重置倒數卡

- 首頁右欄（已登入時）每秒更新：每日商店刷新、夜市結束、配件商店刷新、組合包下架（最早的一個）。
- 還沒同步到每日商店時，依設定的刷新時間推算並以灰字標示。

## 3. 今日小結

- 對戰紀錄頁頂端；只計算已載入、本地日曆日為今天的自己的場次：場數、勝負、勝率、RR 淨變化、K/D、平均 ACS、最常用特務。
  最後一場已載入的仍是今天且還有更多時，提示「只計算已載入的場次」。
- 「分享圖片」：固定 360 寬的小卡（只含自己的數據），以 `RepaintBoundary.toImage` 產生 PNG；
  網頁版下載或 Web Share，Android 系統分享或「建立文件」儲存，iOS 系統分享。

## 4. 本機資料備份

- 白名單：設定、商店歷史、遇過的玩家、同場紀錄、通行證每日經驗、官方購買紀錄、造型實際定價、願望清單、App 更新設定。
- 格式 `{"format":"agent-t-backup","version":1,"exportedAt":…,"data":{key:{"t":型別,"v":值}}}`。
- 匯出：網頁下載／Android 建立文件、系統分享、複製到剪貼簿。還原：選檔（網頁、Android）或從剪貼簿貼上；
  先顯示會被取代的類別再確認；還原後網頁重新載入、App 關閉後重開。
- 不含 token、`ssid`、帳號清單與快取；還原時白名單外的 key 一律略過，設定裡的遠端操作同意一律清除。

## 5. 主題排程

- 設定新增 `themeSchedule`、`themeDayStart`、`themeNightStart`（一天中的分鐘數，預設 07:00／19:00，可以跨午夜）。
- 開啟時 `applyThemeSchedule` 把明暗換成 light／dark 再交給 `ThemeChoice.fromSettings`（不改主題列舉與樣式表）；
  `ThemeScheduleClock` 在切換時間與 App 回到前景時通知 `ThemedApp` 重建。
