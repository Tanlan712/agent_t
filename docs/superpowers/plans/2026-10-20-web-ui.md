# 網頁 UI 優化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal：** 把 Flutter Web App 改成網頁式介面：側邊導覽殼層、響應式網格，以及 VALORANT 深色主題。所有頁面一起改，功能不變。

**Architecture：** 新增 `AppShell`，用 `LayoutBuilder` 依寬度切換 Drawer、NavigationRail 和展開式導覽。頂層路由集中到 `lib/app_routes.dart`，用沒有轉場動畫的 `PageRouteBuilder` 產生，切換頁面時 `pushReplacementNamed`。網格欄數由純函式 `columnsFor` 計算，透過 `ResponsiveGrid` 套用到各頁。主題 tokens 集中在 `lib/theme/app_theme.dart`。

**Tech Stack：** Flutter 3.24.5／Dart 3.5.4、provider。不新增任何套件。

**Spec：** `docs/superpowers/specs/2026-10-20-web-ui-design.md`

## Global Constraints

- 不新增套件，不使用 go_router。
- 斷點：`< 600` 用 drawer，`600–1199` 用 rail，`≥ 1200` 用 extended。內容最大寬度 1280；左右內距在 `≥ 600` 時為 32，`< 600` 時為 16。網格間距 16。
- 色彩 tokens 照 spec 4.1，另外加上以下兩個決定：
  - `primary #FF4655` 用在文字、圖示和選中標示（在 `#0F1923` 上對比 5.29）。
  - **按鈕底色 `buttonRed #D7263D`**，上面放白字（對比 4.96）。原因是白字放在 `#FF4655` 上只有 3.36，未達 AA。
- 稀有度顏色調整（文字放在 `surface #1A2530` 上要 ≥ 4.5）：精選 `#64748B → #94A3B8`、限定 `#8B5CF6 → #A78BFA`、尊爵 `#D946EF → #E879F9`；奢華 `#06B6D4` 和究極 `#EAB308` 不變。
- `lib/` 底下不可以出現寫死的 `Colors.xxx`（`Colors.transparent`、`Colors.white`、`Colors.black` 除外）和 `Color(0x…)`；`lib/theme/app_theme.dart`、`lib/models/tier.dart` 除外。
- 每個 Task 結束時都要通過 `flutter test`（全綠）、`flutter analyze`（沒有新的 warning；check_api_key.dart 和 agents_page.dart:88 的兩個舊 warning 是基準）、`flutter build web`。
- **共用資料夾**：另一個 session 可能同時在開發「當前對局查看」。每個 Task 開始前先執行 `git status` 和 `git log -3`。修改 `lib/main.dart` 之前，如果發現有不是自己的未提交修改，就停下來問使用者。commit 時只加自己改的檔案（不要 `git add -A`）。`.claude/launch.json` 和 `windows/flutter/*` 的既有修改不屬於這個工作，不可以 commit。
- 只在本機 commit，不推送。

## Review Focus

1. **停在頁面上調整視窗大小跨過斷點**：版面在 rail 和 drawer 之間切換時不丟例外，頁面狀態保留。（Task 2）
2. **手機寬度點抽屜裡的導覽項目**：抽屜關閉並換頁，不會留下半開的抽屜或疊出兩頁。（Task 3）
3. **點目前所在的導覽項目**：什麼都不做，不重新 push 同一頁。（Task 3）
4. **很長的造型名稱放在 390 寬的 `SkinCard`**：文字以省略號截斷，沒有 RenderFlex overflow。（Task 4）
5. **Riot 登入狀態在導覽列底部**：未登入顯示「登入 Riot」；登入後顯示名稱；token 過期後回到「登入 Riot」。（Task 2）

### Task 2：殼層基礎：斷點、網格、導覽項目、`AppShell`

**Files：**
- Create：`lib/shell/layout.dart`、`lib/shell/responsive_grid.dart`、`lib/shell/nav_items.dart`、`lib/shell/app_shell.dart`
- Test：`test/shell/layout_test.dart`、`test/shell/app_shell_test.dart`

**Interfaces：**
- Consumes：`AppColors`、`RiotProvider`（`isLoggedIn`、`session.displayName`）。
- Produces：
  - `layout.dart`：`enum NavMode { drawer, rail, extended }`、`NavMode navModeFor(double width)`、`const double contentMaxWidth = 1280`、`double horizontalPadding(double width)`（`< 600` 回傳 16，否則 32）。
  - `responsive_grid.dart`：`const double gridSpacing = 16`、`int columnsFor(double width, double minTileWidth)`（公式照 spec 3.1），以及 `ResponsiveGrid({required double minTileWidth, required double childAspectRatio, required List<Widget> children})`。內部用 `LayoutBuilder` 加上 `GridView.count`（`shrinkWrap: true`、`NeverScrollableScrollPhysics`），讓它可以放在外層的 `ListView` 或 `SingleChildScrollView` 裡。
  - `nav_items.dart`：`class NavItem { final String route; final String label; final IconData icon; final NavGroup group; }`、`enum NavGroup { shop, database, settings }`、`const List<NavItem> navItems`。順序與文字：我的商店 `/`、願望清單 `/wishlist`、角色 `/agents`、武器 `/weapons`、地圖 `/maps`、組合包 `/bundles`、遊戲模式 `/gamemodes`、玩家卡片 `/playercards`、設定 `/settings`。
  - `app_shell.dart`：`AppShell({required String currentRoute, required String title, List<Widget> actions = const [], required Widget child})`。
    - drawer 模式：`Scaffold(appBar: AppBar(title, actions), drawer: Drawer(導覽清單))`。
    - rail 模式：`Row[NavigationRail(labelType: all), VerticalDivider, 內容]`。
    - extended 模式：`Row[NavigationRail(extended: true, minExtendedWidth: 240), VerticalDivider, 內容]`。
    - rail 和 extended 模式下，內容區頂端是一列：標題（`titleLarge`）加 actions。內容置中，最大寬度 `contentMaxWidth`，左右內距 `horizontalPadding`。
    - 導覽 header 是「VALORANT 商店追蹤」。底部的 Riot 狀態項目 key 為 `ValueKey('nav-riot')`：未登入顯示「登入 Riot」，已登入顯示 `session.displayName`，點擊後 `pushNamed('/riot-login')`。
    - 點導覽項目：如果 `item.route == currentRoute` 就什麼都不做；否則 `Navigator.pushReplacementNamed(context, item.route)`。drawer 模式下要先 `Navigator.pop` 關閉抽屜。
