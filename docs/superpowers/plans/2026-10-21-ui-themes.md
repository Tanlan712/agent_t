# 可切換 UI 主題 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 讓使用者在設定頁切換 8 種風格（含導覽與排列）× 4 種主色 × 3 種明暗，EVA 系列另有狀態元件、彩蛋、故事層與機密文件。

**Architecture:** `AppPalette`／`AppStyle` 兩個 ThemeExtension 是唯一來源，由 `buildAppTheme(choice)` 產生；`AppColors.*` 改成轉讀 `AppPalette.current` 的 getter，切換時以 `KeyedSubtree` 重建整棵樹。導覽、頁首、卡片、KPI、格線等排列差異全部放在共用元件與殼層，頁面檔案只拿掉 `const`。

**Tech Stack:** Flutter 3.24.5（Web）、provider、shared_preferences、google_fonts。

**Spec:** `docs/superpowers/specs/2026-10-21-ui-themes-design.md`（各節編號以下簡稱「規格 §x」）

## Global Constraints

- 不新增任何 API 呼叫，不改 provider／service／logic 的行為（AGENTS.md 第 1～3 節）。
- 顏色只能寫在 `lib/theme/app_palette.dart`、`lib/theme/app_theme.dart`、`lib/models/tier.dart`；`lib/` 不可用 `dart:io`；圖示只用 Material Icons，不用 emoji。
- 所有對比數值以規格 §3 的色碼為準，不得自行修改；規則見規格 §3.4。
- 預設主題：`editorial`（A）／`red`／`auto`（A 的預設明暗是淺色）。
- 動態：`MediaQuery.disableAnimationsOf(context)` 為 true 或 `backgroundMotion` 為 false 時靜止；閃爍 ≤ 3 次／秒；不用 `BackdropFilter`、視差、3D。
- 不使用 NERV 字樣、EVA 標誌、角色、原作台詞；文件頁尾用 `VAL-SYS ARCHIVE`。
- 「請勿公開或分享他人資訊」提示不可移除。
- token、PUUID 不出現在任何彩蛋、終端機或文件輸出。
- 測試一律 `buildAppTheme(useGoogleFonts: false)`（`flutter_test_config.dart` 已關閉執行時下載字體）。
- 每期結束：`flutter analyze` 無新 warning、`flutter test` 全過、`flutter build web` 成功。
- 只 commit 到 `claude/ui-themes-30a013`，不推送、不合併。

## Review Focus

1. 在輸入框（搜尋、終端機以外的 TextField）打字時，不可以觸發 `sync`、`` ` ``、Konami 等彩蛋 → Task 17 加測試。
2. 舊版 localStorage 的 `settings`（沒有主題欄位，或欄位是未知字串、型別錯誤）要退回預設，不可丟例外 → Task 1 加測試。

5. 時鐘倒退或同一天重複開啟時，劇集不可重複前進或倒退 → Task 16 加測試。
