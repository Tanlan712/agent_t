# UI 改版 B：儀表板 Bento 風 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal：** 把整個網頁改成儀表板 Bento 風：分組側欄、大標題頁首、圓角卡片與 12 欄 Bento 格。

**Architecture：** 先換掉視覺基礎（CardTheme、`HudCard`→`PanelCard`），再新增 `BentoGrid`／`PageHeader`，然後換殼層側欄，最後逐頁改排版。只動 widget 與 theme，provider、service、logic 一律不改。

**Tech Stack：** Flutter 3.24.5／Dart 3.5.4、provider、google_fonts（只用 Chakra Petch）。

**Spec：** `docs/superpowers/specs/2026-10-21-ui-bento-design.md`

## Global Constraints

- 不新增 API 呼叫；不改 `lib/providers`、`lib/services`、`lib/logic`、`lib/storage`、`lib/models`。
- AGENTS.md 全部適用；既有提示文字（隱私、推測、風險）與測試用的 key（`sus-*`、`live-team-*`、`live-player-*`、`shop-kpi`、`history-kpi`、`player-kpi`、`expiry-banner`）保留。
- 顏色只能來自 `AppColors`（`no_hardcoded_colors_test`）；不用 emoji 圖示；`lib/` 不用 `dart:io`。
- 斷點：< 600 bottom、600–1023 rail、≥ 1024 extended；內容最大寬 1280。
- 卡片圓角 12、邊框 1px `outline`；頁首標題 28px；KPI 數值 24px。
- 不刪除、不搬移檔案（`lib/widgets/hud/` 沿用）；`NotchClipper` 改為不再使用但保留類別到 B7 再由使用者決定是否刪除。
- 每個 task 結束：`flutter analyze` 無新 warning、`flutter test` 全過、`flutter build web` 成功，再 commit。
- 既有測試只更新 finder 與排版斷言，不刪行為斷言；每次更新記在 ledger `.superpowers/sdd/2026-10-21-ui-bento/progress.md`。

## Review Focus

1. 側欄在矮視窗（高 500）與 13 個項目時要能捲動、不 overflow，Riot 狀態卡仍可到達。
2. BentoGrid 在剛好 1024／600 寬（邊界）與 span 大於欄數時不 overflow、不出現 0 寬 tile。
3. 我的商店在「未登入且商店是空的」「已登入但錢包尚未同步」「願望清單有上架」三種狀態都有合理內容，不留空白大卡。
4. 鍵盤：側欄項目、PanelCard（可點擊）、對戰列表列都能用 Tab 聚焦並以 Enter 觸發，焦點可見。
5. 減少動態效果：PanelCard、側欄 hover 動畫在 `disableAnimations` 時為 0ms。
