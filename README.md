# Agent T（VALORANT 商店追蹤器）

Flutter Web 應用程式，提供：

- **遊戲資料瀏覽**：角色、武器、地圖、組合包、遊戲模式、玩家卡片（資料來自 [valorant-api.com](https://valorant-api.com/)）。
- **我的商店**：每日商店、夜市、精選組合包。可以手動輸入，也可以登入 Riot 後自動同步。
- **願望清單**：商店裡出現願望清單上的造型時，會用金框標示並顯示數量。
- **網頁式介面**：VALORANT 風格深色主題；桌機顯示左側導覽列，平板顯示窄導覽列，手機改用漢堡選單；各頁依視窗寬度自動調整欄數。
- **Riot 連動**（選用）：登入後同步商店、錢包餘額（VP／輻能點數／王國幣），並標示已擁有的造型。登入頁有「從剪貼簿貼上並登入」，並記住伺服器區域；登入資訊（token）不保存，到期前 5 分鐘會提醒重新登入。
- **對戰紀錄**（需登入 Riot）：最近的對戰列表（地圖、模式、勝負、比分、K/D/A、RR 變化），可以載入更多；點進去可以看兩隊所有玩家的 Riot ID、特務、牌位、K/D/A、ACS、爆頭率和等級，同一組隊會有相同顏色的標記。頁首顯示目前牌位。定級賽不顯示 RR 變化。
- **玩家表現與玩家紀錄**（需登入 Riot）：單場計分板加上遊戲內的表現分數、K/D、ADR、首殺，以及全場 MVP／隊伍 MVP 標籤；每位玩家的「最近 5 場」會在背景分批載入（勝敗顏色與 ACS、平均 ACS）。點玩家名稱可以查看他的對戰紀錄（每頁 20 場），點自己則回到自己的對戰紀錄。「最近 5 場」只計算與這場相同的模式。
- **即時對局**（需登入 Riot）：遊戲開著時每 10 秒更新（只讀取），自動判斷階段。大廳顯示隊伍狀態與成員（玩家卡、Riot ID、等級、牌位、隊長與準備）；進入對局後自動切換成即時對戰畫面（地圖、模式、雙方 10 人的名稱、特務、等級、本季牌位，以及每人同模式的最近 5 場與平均 ACS；每人下方顯示 Vandal、Phantom、Operator、Sheriff、近戰的造型，可以展開全部）。選角與對局中會依等級、競技總場數、歷史最高牌位與最近 10 場的 ACS、K/D、爆頭率、勝率、特務池計分，標示「疑似小號」「疑似代打」（分數高時為「高度疑似」；只是推測，滑鼠移上去或點一下看各項原因與分數）；選角時顯示地圖、模式、剩餘時間、我方 5 人的特務與選角狀態、牌位與最近 5 場（Riot 不提供對手資料，只顯示敵方人數與已鎖定人數）。
- **遇過的玩家**：載入對戰詳情時，自動記下同場其他玩家的 PUUID 與 Riot ID（最多 500 位，只存在這個瀏覽器）。可以用 Riot ID 搜尋、點擊查看他的對戰紀錄，也可以刪除單筆或全部清除。

## 本機執行

```bash
flutter pub get
flutter run -d web-server --web-port 8642 --web-hostname localhost
```

接著用瀏覽器開啟 http://localhost:8642 。

建置靜態檔：`flutter build web`（輸出到 `build/web`）。

## 安裝成 App

網站支援 PWA，可以像 App 一樣從主畫面開啟（全螢幕、有自己的圖示，直向橫向都能用）：

- **Android（Chrome）**：開啟網站 → 右上角選單 →「安裝應用程式」或「加到主畫面」。
- **iPhone／iPad（Safari）**：開啟網站 → 分享按鈕 →「加入主畫面」。
- **電腦（Chrome／Edge）**：網址列右側的安裝圖示。
- **Android App（APK）**：另外有可以側載安裝的 App，支援在 App 內直接登入 Riot，見 [docs/android.md](docs/android.md)。
- **iOS App**：用自己的免費 Apple ID 簽章安裝（每 7 天重裝一次），見 [docs/ios.md](docs/ios.md)。

安裝後仍然是同一個網站，網站更新後重新開啟就會套用。Android 與電腦的資料和瀏覽器共用；iPhone 加入主畫面後的資料與 Safari 分開，需要在 App 裡另外登入一次。

## Riot 登入方式

1. 進入「設定 → Riot 帳號」，或在「我的商店」點「登入 Riot 以自動同步」。
2. 按「開啟 Riot 登入頁」（或複製登入網址），在 Riot 官方頁面登入。
3. 登入後網頁會跳到 `playvalorant.com`，把網址列的**完整網址**貼回 App，再按「完成登入」。

App 不會接觸密碼。登入資訊只保留在分頁的記憶體裡，重新整理頁面或約 1 小時後需要重新登入。

## ⚠️ 注意事項

- 商店、錢包、已擁有造型使用的是 **Riot 未公開的 API**，可能違反服務條款、帳號有受處分的風險，API 也可能隨時失效。建議使用非主要帳號。
- 資料（商店、願望清單、造型目錄快取）只存在這個瀏覽器的 localStorage 裡。
- 對戰紀錄的玩家名稱來自 Riot 的 name-service，可能包含在遊戲中選擇隱藏名稱的玩家，請勿公開或分享他人資訊。
- 「遇過的玩家」存在瀏覽器的 localStorage，不會上傳；清除網站資料或按「全部清除」即可刪除。
- **部署前必須處理**：`pubspec.yaml` 目前把 `.env` 列成 asset，網頁建置後 `.env` 會成為可以公開下載的檔案。
